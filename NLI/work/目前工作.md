zero-shot
简单结构与复杂结构
选定概率，p=0.5，满足二项分布
让大约一半对象满足谓词，将关系密度控制在大约一半附近，可以让公式为真和为假的机会不至于过度失衡，也能让算法更快找到符合预定标签的结构。



1. 随机选择句子模板和词汇
2. 生成逻辑公式 φ
3. 随机选择标签 True 或 False
4. 根据模板：
   - True：加入必要的见证
   - False：加入必要的反例
5. 随机补全其他事实，但不能破坏目标标签
6. 将结构转换成自然语言
不要让所有 True 样本都“恰好有一个见证”，或者让所有 False 样本都“恰好有一个反例”，否则又会出现新的统计规律。解决办法也很简单：随机改变见证和反例的数量，并让真假样本的谓词密度大致相同。
