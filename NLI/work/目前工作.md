方法一：回译成逻辑形式
将改写后的自然语言重新解析为逻辑公式，然后检查前后逻辑是否等价？等价就保留，不等价就删除，实际中可以先让系统将自然表达回译成标准模板，再由确定性的模板解析器转换成逻辑公式。
$$
\text{原公式 }\varphi \rightarrow \text{自然语言改写} \rightarrow \text{标准模板} \rightarrow \text{回译公式 }\psi
$$

==不能把同一个改写器产生的数据随机拆成训练集和测试集，否则模型仍可能学习改写器的风格。==
更合理的划分是：
- 训练集：模板系统 A、大模型 A 和 B 的改写；
- 验证集：未见过的模板系统 B；
- 测试集：大模型 C 的改写和人类撰写样本。


词汇、句法和篇章结构也应分别留出：
- 训练时只看部分同义表达；
- 测试时使用新的同义词和句式；
- 训练时事实按固定顺序出现；
- 测试时改变顺序、合并句子和加入干扰事实。


数据泄露？
训练集：
- Every artist is a musician.
- Some artist is not a musician.
测试集：
- Every doctor is a singer.
- Some doctor is not a singer.
简单语言片段中的不可满足性往往可以通过较短的 forbidden configuration 判断。这意味着随机切分很容易让相同或高度相似的“最小不可满足核心”同时出现在训练集和测试集。
这更适合叫**推理模式泄露或局部证明泄露**。
