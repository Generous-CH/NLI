# 项目开发任务书：Generalized Quantifier × Modal Logic Benchmark

## 0. 项目目标

我要开发一个用于研究 **Large Language Models（LLMs）逻辑推理能力**的实验系统。

我已有一个能够进行 **Generalized Quantifier Model Checking** 的基础系统，现在希望在此基础上扩展到：

> **Generalized Quantifier + First-Order Modal Logic**

第一阶段只研究 **Normal Modal Logic K**，暂时不要实现 T、S4、S5、Deontic Logic 等其他系统。

核心研究问题：

1. LLM 是否能够正确理解广义量词与模态算子的组合？
2. LLM 是否能够区分不同的 quantifier/modal scope？
3. 当同一个逻辑语义用不同自然语言表达时，LLM 的判断是否保持一致？

---

# 1. 当前研究背景

已有系统支持以下广义量词：

- All
- Some
- Most
- Few
- At least
- At most
- More than
- Less than
- Equal

已有系统的基本思想是：

```
Natural Language
        ↓
Generalized Quantifier
        ↓
Set / Cardinality Relation
        ↓
True / False
```

例如：

> Most students are scientists.

对应：

Most(Student,Scientist)Most(Student, Scientist)

程序通过比较：

∣Student∩Scientist∣|Student\cap Scientist|

与：

∣Student∣|Student|

得到 True / False。

现在需要增加 Modal Logic。

---

# 2. 第一阶段只实现 Modal Logic K

**非常重要：第一阶段只实现 K。**

不要实现：

- T
- S4
- S5
- Deontic Logic
- varying-domain semantics
- 复杂 FOL
- 神经符号模型

K 的特点：

> 对 accessibility relation RR 不增加自反、对称、传递等额外约束。

因此：

M,w⊨□ϕM,w\models\Box\phi

定义为：

∀v∈W,(wRv⇒M,v⊨ϕ)\forall v\in W,\quad (wRv\Rightarrow M,v\models\phi)

即：

> ϕ\phi 在当前世界 ww 的所有可达世界中都成立。

而：

M,w⊨◊ϕM,w\models\Diamond\phi

定义为：

∃v∈W,(wRv∧M,v⊨ϕ)\exists v\in W,\quad (wRv\land M,v\models\phi)

即：

> 至少存在一个从 ww 可达的世界，使得 ϕ\phi 成立。

---

# 3. 一个非常重要的语义约定

在 K 中：

wRwwRw

**不一定成立。**

所以“所有可达世界”：

> 不意味着一定包括当前世界。

是否包括当前世界完全由 RR 决定。

例如：

R(w1)={w2,w3}R(w_1)=\{w_2,w_3\}

那么：

w1w_1

本身不属于可达世界。

因此：

w1⊨□Pw_1\models\Box P

只需要检查：

P@w2P@w_2

和：

P@w3P@w_3

不检查：

P@w1P@w_1

---

# 4. Kripke Frame 与 Model 必须分开设计

需要明确区分：

## Kripke Frame

F=(W,R)F=(W,R)

其中：

- WW：世界集合
- RR：accessibility relation

## First-Order Kripke Model

第一阶段采用固定域：

M=(W,D,R,V)M=(W,D,R,V)

其中：

- WW：可能世界集合
- DD：个体域
- RR：世界之间的可达关系
- VV：谓词在不同世界中的解释

这里的 DD 是因为我们的研究已经不是单纯的 propositional modal logic，而是：

> First-Order Modal Logic + Generalized Quantifiers

---

# 5. Domain 采用 Constant Domain

第一阶段明确采用：

Dw=DD_w=D

即所有世界共享同一个个体域。

例如：

D={Alice,Bob,Charlie,David}D=\{Alice,Bob,Charlie,David\}

所有世界都有这些个体。

但是不同世界中这些个体的性质可以不同。

例如：

```
World W1:
Alice Scientist
Bob Scientist

World W2:
Alice Scientist
Bob NOT Scientist
```

因此：

> 个体存在性固定，但谓词真值可以随世界改变。

暂时不要实现 varying-domain semantics。

# 6. Valuation 的定义

对于一元谓词：

PP

在世界 ww 中：

V(w,P)⊆DV(w,P)\subseteq D

例如：

V(w1,Scientist)={Alice,Bob}V(w_1,Scientist)=\{Alice,Bob\}

表示：

Scientist(Alice)Scientist(Alice)

和：

Scientist(Bob)Scientist(Bob)

在 w1w_1 中为真。

代码可以采用：

```
valuation = {
    "w1": {
        "Scientist": {"Alice", "Bob"}
    },
    "w2": {
        "Scientist": {"Alice"}
    }
}
```

项目真正的核心不是简单地：

> “给广义量词加上 □ 和 ◇。”

而是研究：

□QP\boxed{\Box QP}

Q◊P\boxed{Q\Diamond P}

◊QP\boxed{\Diamond QP}

# 9. Scope 类型

第一阶段至少实现四种结构。

## Type 1

Qx(P(x),□R(x))Q_x(P(x),\Box R(x))

例如：

> At least two students must be scientists.

形式化：

AtLeast2(Student,□Scientist)AtLeast_2(Student,\Box Scientist)

---

## Type 2

□Qx(P(x),R(x))\Box Q_x(P(x),R(x))

例如：

> Necessarily, at least two students are scientists.

形式化：

□AtLeast2(Student,Scientist)\Box AtLeast_2(Student,Scientist)

---

## Type 3

Qx(P(x),◊R(x))Q_x(P(x),\Diamond R(x))

例如：

> At least two students can be scientists.

形式化：

AtLeast2(Student,◊Scientist)AtLeast_2(Student,\Diamond Scientist)

---

## Type 4

◊Qx(P(x),R(x))\Diamond Q_x(P(x),R(x))

例如：

> Possibly, at least two students are scientists.

形式化：

◊AtLeast2(Student,Scientist)\Diamond AtLeast_2(Student,Scientist)

---

# 10. 特别注意：这些结构一般不等价

必须在系统中严格区分：

Q□PQ\Box P

和：

□QP\Box QP

以及：

Q◊PQ\Diamond P

和：

◊QP\Diamond QP

不能把它们当成同一个东西。

例如：

AtLeast2(Student,□Scientist)AtLeast_2(Student,\Box Scientist)

含义是：

> 至少有两个学生，在所有可达世界中都是科学家。

而：

□AtLeast2(Student,Scientist)\Box AtLeast_2(Student,Scientist)

含义是：

> 每一个可达世界中，都至少有两个学生是科学家。

这是两个不同的语义结构。

# 11. Modal Evaluator

首先实现最基本的 evaluator：

```
evaluate_atom(model, world, predicate, individual)
```

判断：

M,w⊨P(a)M,w\models P(a)

---

然后实现：

```
evaluate_box(model, world, formula)
```

逻辑必须严格按照：

M,w⊨□ϕ  ⟺  ∀v(wRv⇒M,v⊨ϕ)M,w\models\Box\phi \iff \forall v(wRv\Rightarrow M,v\models\phi)

伪代码：

```
def evaluate_box(model, world, formula):
    for accessible_world in model.accessible(world):
        if not evaluate(model, accessible_world, formula):
            return False
    return True
```

---

Diamond：

```
def evaluate_diamond(model, world, formula):
    for accessible_world in model.accessible(world):
        if evaluate(model, accessible_world, formula):
            return True
    return False
```
# 12. Empty Accessibility 的问题

需要明确处理：

R(w)=∅R(w)=\emptyset

这种情况。

按照标准 Kripke 语义：

### Box

∀v(wRv⇒ϕ)\forall v(wRv\Rightarrow\phi)

在没有可达世界时是 vacuously true。

因此：

□ϕ=True\Box\phi=True

---

### Diamond

∃v(wRv∧ϕ)\exists v(wRv\land\phi)

没有可达世界，因此：

◊ϕ=False\Diamond\phi=False

第一版必须按照这个标准语义实现。

---

# 13. Generalized Quantifier + Modal 的计算

例如：

AtLeast2(Student,□Scientist)AtLeast_2(Student,\Box Scientist)

计算步骤：

### Step 1

找出所有 Student：

S={x∈D:Student(x)}S=\{x\in D:Student(x)\}

---

### Step 2

对于每一个学生 xx，判断：

M,w⊨□Scientist(x)M,w\models\Box Scientist(x)

---

### Step 3

构造：

S′={x∈S:M,w⊨□Scientist(x)}S'= \{x\in S: M,w\models\Box Scientist(x)\}

---

### Step 4

检查：

∣S′∣≥2|S'|\geq2

---

例如：

```
Alice → □Scientist = True
Bob → □Scientist = False
Charlie → □Scientist = True
David → □Scientist = False
```

则：

∣S′∣=2|S'|=2

因此：

AtLeast2(Student,□Scientist)=TrueAtLeast_2(Student,\Box Scientist)=True

---

# 14. AtMost

对于：

AtMost2(Student,□Scientist)AtMost_2(Student,\Box Scientist)

首先得到：

S′S'

然后判断：

∣S′∣≤2|S'|\leq2
